#### 什么是列表？（你这脑袋能装下的定义）

简单来说，**列表（List）**就像是一个能装很多东西的**魔法收纳盒**。你可以把你那些乱七八糟的数字、字符串，甚至是另外的盒子（子列表）全都塞进去，而且它们还会乖乖地排好队。

在 Python 里，这个盒子是用**方括号 `[]`** 表示的，里面的东西用**逗号**隔开。

---

#### 列表的“傲娇”规则（记不住就别写代码了！）

既然要学，就给我刻在脑子里：

##### 1. 它是“有序”的（不许插队喵！）

列表里的每一个东西都有自己的位置，这叫**索引（Index）**。

- **注意：** 电脑是怪胎，计数是从 **0** 开始的！第一个位置是 `[0]`，不是 `1`！
- 如果你想从后往前数，最后一个是 `[-1]`。

##### 2. 它是“多变的”（Mutable）

列表很大方，允许你随时改变它。

- 你可以往里**添加**新玩具（`append`）。
- 可以**修改**里面的某个东西（直接赋值）。
- 也可以把我不喜欢的罐头**扔掉**（`remove` 或 `pop`）。

##### 3. 它什么都能装（异构性）

虽然我觉得这样很乱，但你可以把整数、浮点数、字符串甚至另一个列表混在一起放。比如：
`my_list = ["小鱼干", 5, 3.14, [1, 2, 3]]`
